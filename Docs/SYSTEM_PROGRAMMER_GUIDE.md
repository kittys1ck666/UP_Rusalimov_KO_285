# Руководство для системного программиста

## 1. Сведение о программе
Программный модуль для учета заявок на ремонт климатического оборудования.
Заказчик: ООО "Конди".
Исполнитель: Сервисный центр "IT-Сфера".

Программный модуль реализован через:
- BACKEND: ASP.NET Core Web API
- FRONTEND: HTML, CSS, JavaScript
- База данных: PostgreSQL

## 2. Требования к программным и техническим средствам

### 2.1 Технические требования
Для работы программы рекомендуется использовать персональный компьютер со следующими характеристиками:
- процессор: не ниже Intel Core i3 / AMD Ryzen 3;
- оперативная память: не менее 4 ГБ;
- свободное место на диске: не менее 1 ГБ;
- доступ к локальной сети или localhost.
- (также можно развернуть на сервере с примерно такими же характеристиками)

### 2.2 Программные требования
Для развертывания и запуска программы требуется следующее программное обеспечение:
- операционная система: Windows 10/11;
- .NET SDK 9.0 или выше;
- PostgreSQL 17 или выше;
- pgAdmin 4 или DBeaver для администрирования БД;
- современный веб-браузер: Google Chrome, Microsoft Edge, Yandex Browser;
- Git (по необходимости для работы с репозиторием).

## 3. Работа с приложением

### 3.1 База данных 
BACKUP'ы и данные для импорта в формате csv,txt,xlsx лежат в папке UP_CONDI_V5/SQL (данные закодированы в UTF-8)

### 3.2 Настройка конфигурации приложения
Для корректной работы необходимо настроить файл appsettings.json (на git'e он не отображается в виду безопастности пользователей)

Необходимо настроить:
DefaultConnection - подключение к БД PostgreSQL;
Issuer - издатель JWT-токена;
Audience — получатель JWT-токена;
Key — секретный ключ подписи токена;
ExpireMinutes — время жизни токена в минутах.

### 3.3 Первоначальный запуск
Убедитесь, что все необходимые NuGet пакеты уставновлены:
```bash
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer --version 9.*
dotnet add package Microsoft.AspNetCore.Mvc.NewtonsoftJson --version 9.*
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL --version 9.*
dotnet add package Microsoft.EntityFrameworkCore.Design --version 9.*
dotnet add package Swashbuckle.AspNetCore.Swagger --version 9.*
dotnet add package Swashbuckle.AspNetCore.SwaggerGen --version 9.*
dotnet add package Swashbuckle.AspNetCore.SwaggerUI --version 9.*
```
В каталоге проекта выполнить: 
```bash
dotnet restore
dotnet build
dotnet run
```
Далее будет выдан адрес по которому будет доступен сайт.

### 3.4 Проверка запуска
После старта необходимо убедиться, что:
- сервер запускается без ошибок;
- Swagger открывается;
- фронтенд-страница открывается в браузере;
- авторизация работает корректно;
- выполняется подключение к БД.

Если, что-то пойдет не так, проверьте, что appsetting.json настроен корректно и все ли зависимости подтянул dotnet.

## 4. Структура проекта (backend)
Проект выполнен на базе ASP.NET Core Web API:

Program.cs - выполняется запуск программы, прописываются необходимые для запуска команды;

Models/ - здесь хранятся модели базы данных, модели хранят в себе все атрибуты таблиц;

Data/ - здесь хранится контекст базы данных (объявление таблиц и связей между ними);

Controllers/ - обработчик запросов, имеют базовую CRUD структуру;

Constants/ - хранит в себе класс Roles, чтобы выдавать доступ к методам контроллеров более точно и разделять пользователей на роли;

DTOs/ - Data Transfer Object, нужен для передачи данных между клиентом и сервером, также, чтобы не отправлять лишние поля и передавать, то что нужно. Помогает стабилизировать данные для API, чтобы backend не падал в ошибки;

Services/ - здесь реализованны методы безопастности, такие как хэширование пароля и выдача JWT токена пользователю;

appsettings.json - базовая настройка подключение к PostgreSQL через Npgsql.EntityFrameworkCore.PostgreSQL.

## 5. Структура проекта (frontend)
index.html и login.html - разметки HTML для сайта;

site.css - хранит стили для сайта;

app.js - управляет логикой клиентской части + генерирует QR-код на ссылку для опроса

## 6. Возможные ошибки

### 6.1 Приложение не запускается
- Не установлены все зависимости через dotnet restore;
- Ошибка в подключении БД.

### 6.2 Ошибка подключения к PostgreSQL
- Сервер не запущен или упал в ошибку;
- Неверные данные подключения БД в appsettings.json.

### 6.3 Ошибка авторизации на сайт
- Проверьте выдается ли корректный JWT-токен пользователю;
- Токен отсутствует или истёк;
- Не настроены Issuer и Audience в appsettings.json
